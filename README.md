# Margarita Colombo

Personal website for Margarita Colombo, Fractional CMO and AI Workflow Consultant.

This is a static HTML, CSS and JavaScript site deployed with Vercel.

## Files

- `index.html`: homepage and SEO metadata
- `styles.css`: responsive styles, branding and motion
- `script.js`: navigation, scroll reveal and typewriter effects
- `images/`: archival imagery with source and license credits shown on the website
- `robots.txt` and `sitemap.xml`: search engine discovery
- `favicon.svg`: site icon
